# QuizMaster - Interactive Web Quiz Application

## Project
A simple interactive multiple-choice quiz application made using:
- HTML
- CSS
- JavaScript

## Features
- Multiple quiz topics
- Student can choose any topic
- Multiple-choice questions
- Immediate answer feedback
- Live score
- Progress bar
- Final result and percentage
- Retry quiz
- Choose another topic
- Responsive design for mobile and desktop

## How to run
1. Extract the ZIP file.
2. Open the `quiz_application` folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click `index.html` and choose "Open with Live Server" if Live Server is installed.
5. You can also double-click `index.html` to open it directly in a browser.
